🌍 Прогноз по региону · Россия

Прогноз для России, Турции и ОАЭ по точкам городов: осадки, ветер, температура, CAPE и вероятность осадков. CAPE показывает энергию для развития конвекции, но сам по себе не означает грозу или опасность. Вероятность осадков — шанс осадков по модели, а не вероятность опасного явления. Это не метеорадар, не измерения с метеостанций и не официальное предупреждение.

Выберите Россию, Турцию или ОАЭ в разделе «Города»

Проверка опубликованного прогноза каждую минуту; серверный снимок обновляется по GitHub Actions примерно раз в 15 минут (запуск может задерживаться). Новые значения появляются только когда их обновит источник. Данные по отдельным городам, а не непрерывная карта осадков. Отсутствие отметки не означает безопасности. При угрозе проверяйте Гидрометцентр и МЧС России. При чрезвычайной ситуации в России — 112.

Источник: Open-Meteo, модельный прогноз (CC BY 4.0). Для экстренных решений используйте официальные сообщения.

Проверяем поля CAPE и ветра для кандидатов S?…

S? · модельный кандидатMESO · NEXRADTVS · NEXRAD

S? рассчитывается по CAPE и приближённому сдвигу ветра 10 м–500 гПа на редкой сетке точек. Нет меток — не значит нет угрозы. Это не обнаруженная суперячейка. MESO и TVS — радарные признаки, не подтверждённый торнадо. Опасные границы рисуются только из официальных предупреждений.
